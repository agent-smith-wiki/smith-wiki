A virtual machine (VM) is a software-created duplicate of a computer that presents the same interface and behaviour as the real hardware beneath it, so that software running inside it executes as if on the physical machine. A [[Hypervisor]] creates and enforces this environment, and the software inside — typically a complete guest operating system — cannot distinguish it from the hardware being imitated.
