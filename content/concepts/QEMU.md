QEMU is a free and open-source machine emulator and virtualizer. In system-emulation mode it provides a virtual model of an entire machine — CPU, memory and emulated devices — that can run an unmodified guest operating system, and in user-mode emulation it runs individual processes compiled for one CPU on another. It is a component of hardware-accelerated [[hypervisor]] stacks such as [[KVM]] and [[Xen]], and the machine-emulation core of front-ends such as [[UTM]].
