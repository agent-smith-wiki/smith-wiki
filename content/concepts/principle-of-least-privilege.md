title: Principle of least privilege
type: concept
description: Every program and user should operate using the least set of privileges necessary to complete the job.

The principle of least privilege holds that every program and user should operate using the least set of privileges necessary to complete the job, and nothing more. Its purpose is to limit the damage — the [[Blast radius]] — that can result from an accident, error, or compromise, since a component can only misuse what it was actually granted.
