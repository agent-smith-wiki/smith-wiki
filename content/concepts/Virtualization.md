---
title: Virtualization
type: concept
description: Software abstraction that turns one physical computer into one or more independent virtual machines.
tags: [:computing, :systems, :infrastructure]
---

Virtualization is the use of software — typically a [[Hypervisor]] — to abstract a computing resource, most commonly a whole physical computer, into one or more virtual versions of itself, so that a single machine can appear as several independent [[Virtual machine]]s.
