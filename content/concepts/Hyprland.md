Hyprland is an independent, dynamic tiling compositor for the [[Wayland]] display protocol, written in C++ and released under the BSD 3-Clause licence (https://en.wikipedia.org/wiki/Hyprland). Acting as the display server for a graphical session, it manages windows in the manner of a [[Tiling window manager]] while its custom compositing renderer supplies animations, rounded corners, blur and shadows, giving keyboard-centric tiling workflows the visual polish of a conventional desktop (https://github.com/hyprwm/Hyprland; https://wiki.archlinux.org/title/Hyprland).
