title: Sandbox (computing)

---

A **sandbox** is a security mechanism that confines the execution of a program within a restricted, tightly controlled environment, so that untrusted, untested, or potentially malicious code cannot harm the host system. The name is a metaphor drawn from a child's sandpit — a bounded area where one can experiment without causing real-world damage.

Sandboxing is implemented by running software under a restricted operating-system environment that controls which system resources a process may access, such as the file system, the network, or memory.
