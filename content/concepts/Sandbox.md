---
title: Sandbox
type: concept
description: A security mechanism that isolates a running program in a tightly controlled environment so its failures or malicious behaviour cannot spread to the host.
tags: [security, isolation, sandboxing]
---

A sandbox is a security mechanism that separates a running program from the rest of the system, confining it to a tightly controlled set of resources — scratch storage, memory, filtered system calls, restricted network access — so that its failures or malicious behaviour cannot spread to the host.
