# Tool use

**Tool use** is the capability of a [[Large language model]] to call external functions, APIs, or programs by emitting a structured request — a tool name and its arguments — extending the model beyond its pretrained parameters to live data, exact computation, and actions in other systems (https://arxiv.org/abs/2304.08354).
