---
title: "Per-agent MCP"
type: concept
by: "Andy Smith"
---

Each agent's only channel back into the [[Agent orchestrator]]: a small MCP surface whose central tool is [[Code-mode eval]] against that agent's [[Capability grant]]. Access is scoped per agent, so one agent cannot reach another's tools.
