title: "Private/Public Note Split"
type: concept
tags: ["note-taking", "privacy"]
---

The problem of separating a personal note corpus into private and publishable parts so that an automated pipeline only exposes the public part.

The source treats a reliable split as essentially impossible when an [[Auto-Researcher]] is the one doing the filtering: it will let something private slip through one way or another. Compare the alternative in [[Public-First Note-Writing]].
