---
title: "The orchestrator can create agents itself"
type: concept
by: "Andy Smith"
---

The [[Agent orchestrator]] does not only run agents declared by a person; it can create new agents on its own, either by hardcoded logic or from the output of other agents. The fleet is generated by the organization's own running system — [[Company as code]] — rather than assembled by hand, which is what lets an [[AI-native company]] [[Humans set the rules of an organization's evolution|evolve within human-set rules]]. Each spawned agent is still just an [[Ephemeral agent]]: sandboxed, [[Role-gated access to shared context|role-gated]], disposable. See [[Job dispatch]] for work flowing down the delegation tree, and [[Reconcile identities from a declaration]] for provisioning the identities those agents need.
