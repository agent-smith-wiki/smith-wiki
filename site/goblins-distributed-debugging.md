Debugging support integrated into the [[Goblins]] distributed programming environment rather than treated as an external concern. It accompanies [[Distributed object programming]], [[Goblins local transactions]], and remote [[Location-transparent asynchronous object interaction]].

The project overview characterizes the tools as powerful but gives no mechanisms, workflow, or evaluation. The only grounded conclusion from this source is that distributed debugging is an explicit part of the environment's design surface.
