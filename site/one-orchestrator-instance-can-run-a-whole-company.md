---
title: "One orchestrator instance can run a whole company"
type: claim
by: "Andy Smith"
status: "tentative"
---

A single long-lived [[Agent orchestrator]] can serve many roles and run a whole unit — a team, a department, a company — because privacy and authority live in each per-agent [[Capability grant]], not in process separation. Scale out into more instances only at genuine trust or autonomy boundaries ([[Bounded context]]).
