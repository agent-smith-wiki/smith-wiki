The project repository describes [[Cap’n Web]] as a JavaScript/TypeScript-native [[Object-capability RPC]] system with bidirectional calls, pass-by-reference, [[Promise pipelining]], multiple transports, and no dependencies. Its current README states a bundle size under 16 kB, superseding the launch article’s under-10-kB figure as the current project claim.
