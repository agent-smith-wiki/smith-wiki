---
title: "Capability grant"
type: concept
by: "Andy Smith"
---

The set of verbs an agent may call, injected by the [[Agent orchestrator]]. Deny-by-default: only the granted vocabulary exists, so adding power is a code edit, not prompt text. The grant is per-agent and chosen by the orchestrator — not necessarily minimal, but always explicit.
