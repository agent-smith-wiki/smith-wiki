Buzz is an open-source, Nostr-based workspace where humans and agents are first-class members of the same channels and threads. Every action is a signed event in one shared log, and an agent is an identity (a keypair), not a process, so its [[Disposable agent body|body]] is replaceable while its identity, memory and reputation persist. It ships chat and forum surfaces, git hosting, a workflow engine, and remote-agent deployment through a swappable provider. A reference point for running agents in a shared, orchestrated context.
