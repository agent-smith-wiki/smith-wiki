Birgitta Böckeler's split, via [[Agent harness (en.wikipedia.org)|Wikipedia]]: the **inner harness** ships with the model's builder — an agent SDK, or a coding tool like Cursor or Codex. The **outer harness** is what the user assembles around it: instruction files, MCP servers, custom skills, and the guides (which steer the agent before it acts) and sensors (which observe the result and let it self-correct), each of which may be computational — linters, tests — or inferential, such as an LLM as judge.

Inference from this wiki, not from the source: on that split [[Zeno]] is the outer harness — dispatch, secrets, sandboxing, sessions — while [[omp]] and [[fx.sh]] are inner harnesses it could swap between.
