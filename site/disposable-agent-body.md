---
title: "Disposable agent body"
type: concept
by: "Andy Smith"
---

An agent's identity, memory and history live off the machine (on the shared log or in a store), so the running process — the body — is replaceable. Reviving an agent is a resurrection, not a rebirth: fresh compute, same agent.
