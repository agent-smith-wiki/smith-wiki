Manifest is an open-source LLM gateway: it puts your API keys, subscriptions and local models behind one OpenAI-compatible endpoint, with routing, per-request cost tracking, full request logs, and fallback on failed requests. Useful as the single model-access layer for an [[Agent orchestrator]]: every agent's model call goes through it, so routing and spend stay governed in one place.
