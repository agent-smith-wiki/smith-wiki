---
title: "Ask-user"
type: concept
by: "Andy Smith"
---

A capability that lets an agent ask a human and suspend, resuming when the answer arrives — over whatever channel the team already uses (chat, issues, email). It separates communication from work, so the agent's logic does not care which channel carries the question.
