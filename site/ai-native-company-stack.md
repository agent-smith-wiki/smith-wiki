The layers an [[AI-native company]] runs on: a communication layer where humans and agents talk over any channel, an orchestration layer that runs the processes and spawns agents (an [[Agent orchestrator]]), and an infrastructure layer you own ([[nixops]]). Each is a small tool adoptable on its own. [[Reflection.dev]] is the framework that binds the orchestration layer into a company-as-code description ([[Describe a company as code]]).
