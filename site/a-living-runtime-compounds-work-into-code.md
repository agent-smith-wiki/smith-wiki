---
title: "A living runtime compounds work into code"
type: claim
by: "Andy Smith"
status: "speculative"
---

A bet: an always-on runtime that turns each worked-out task into reusable, deterministic code gets cheaper per task the more it runs, while stateless agents that re-solve every task from scratch stay flat-cost forever. The first run of a process is the expensive one; once it is captured as [[Deterministic process, stochastic where needed|deterministic process]], repeats run without paying a model again. Experience accretes into an asset instead of evaporating. Unproven at scale — the falling cost-per-task curve is the thing to demonstrate, one workflow at a time.
