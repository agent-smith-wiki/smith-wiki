---
title: "Public-First Note-Writing"
type: concept
tags: ["note-taking", "privacy", "local-first"]
---

Response to the [[Private/Public Note Split]]: only write notes you would be happy to publish, so the entire corpus is safe for an [[Auto-Researcher]] to read. Privacy is enforced by the human at authorship time, not by a filter downstream.

This is structurally similar to [[Work with the garage door up (notes.andymatuschak.org)|Work with the garage door up]] — both publish a working corpus rather than only finished output — but the motivation differs: Matuschak's is audience, serendipity and honesty about process, whereas here public-first is a privacy precondition for letting an autonomous agent read everything.

Tradeoff: it eliminates the leak risk structurally, but it may change what gets written down — see the open question [[What does a knowledge base lose when it is written public-first?]].
